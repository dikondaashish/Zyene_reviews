## How to use

1. Copy UTM links from [PHASE3_DISTRIBUTION_PACKAGE.md](./PHASE3_DISTRIBUTION_PACKAGE.md) or build with the pattern below.
2. Post on the channel; paste the live **post URL** in the tracker.
3. Record impressions/clicks from each platform’s analytics (or `—` until available).
4. Do **not** mark a row **Posted** without a real URL.

**UTM pattern (example):**

```text
https://www.zyenereviews.com/resources/review-request-templates?utm_source=linkedin&utm_medium=social&utm_campaign=template_pack_w1
```
